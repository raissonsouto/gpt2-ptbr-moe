# Data

Not versioned. Place here the package distributed in the course:

- `train.txt`, `val.txt`: introductions of UFCG academic works, stratified by center (20,722 / 1,152 documents).
- `tokenizer.json`: 16k BPE reference tokenizer, trained on the training split only.
- Per-document metadata (center, program, type, year), including `sigla_centro`.

The test split is released only after the final deadline.
